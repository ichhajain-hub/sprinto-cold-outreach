You are extracting structured facts about a company from the text of its own
public web pages. Your output will drive a sales-qualification pipeline for
Sprinto (compliance automation). Downstream code will refuse to send any email
that contains facts not supported by the evidence here — so correctness matters
more than completeness.

RULES
1. Only use facts that appear verbatim or near-verbatim in the text below.
   Never invent, broadly infer, or guess. If in doubt, return null.
2. Every value you return MUST include a source_url that is EXACTLY one of the
   page URLs shown as "===== URL: xxx =====" headers in the input. No other URL
   is allowed, even if it appears inside the text.
3. For list fields, pick the ONE page URL where that list was best supported
   (the page where you saw the most items). If nothing on any page supports
   the list, return [] and null for source_url.
4. For single-value fields where nothing is supported, return null for both
   `value` and `source_url`. Missing is correct; guessing is not.
5. `login_or_trial_link`: pick the full URL from a text like
   "[-> https://app.example.com/login]" where the anchor text is Login /
   Sign in / Open app / Get started / Start free trial / Create account.
   Prefer links on a different subdomain (app.*, dashboard.*, go.*) when
   available; same-domain /login is also fine.
6. `industry`: exactly one of: fintech, healthtech, hrtech, devtools, other.
   If uncertain, pick "other". Do not invent new values.
7. `cloud_provider`: one of: aws, gcp, azure, or null.
8. `compliance_mentions`: short strings like "SOC 2 Type II", "ISO 27001",
   "GDPR", "HIPAA". Include "SOC 2 in progress" / "working toward X" verbatim
   when stated. If a certification is explicitly held, include it.
9. `open_roles`: only roles explicitly listed as open on a careers page. Keep
   the exact posted title.
10. `customer_logos`: only brands named on the page as customers or in case
    studies. Not investors, not partners, not advisors.
11. `funding_mentions`: short strings like "Series B, Mar 2025, $50M led by X".
    If none, [].
12. `employee_count`: a number as a string ("147") or a range ("50-200").
    Null if not stated. Do not estimate from team-page photos.
13. `business_model`: one short phrase. "SaaS", "subscription software",
    "freemium SaaS", "self-serve + enterprise", "open-source with hosted tier",
    "services firm", "agency", "D2C", "hardware", "marketplace", "other".

Return ONLY a JSON object matching the schema. No prose. No markdown fences.
